# RC Airplane — Design, Fabrication & Flight Testing ✈️

**Independent engineering project | Summer 2025**

![RC airplane under construction](images/IMG_5593.jpg)

## Overview
Designed, assembled, iterated, and flight-tested a foam fixed-wing radio-controlled airplane. Work included airframe fabrication, structural redesign, weight distribution, battery selection, wiring refinement, and preliminary ground testing.

**Flight result:** Approximately **1 minute 29 seconds (89 seconds)** of flight before a crash during my first experience piloting an RC aircraft. The exact cause of the crash has not been established.

## Engineering work
- Shaped foam wing panels and built a tapered fuselage and tail.
- Rebuilt structural sections to improve balance and durability.
- Evaluated battery weight, wing mounting, and servo placement.
- Revised wiring and researched control-surface calibration.
- Conducted ground-roll/taxi checks before the flight attempt.
